## 💻 Principais conceitos

### Algoritmos

- Sequência de passos para resolver um problema.
- Devem possuir uma lógica clara e bem definida.
- Programas são algoritmos implementados em uma linguagem de programação.

### Representação de informações

- Computadores utilizam bits para representar informações.
- Um bit pode assumir os valores `0` ou `1`.
- Combinações de bits podem representar números, textos, imagens e sons.

### Abstração

- Esconde detalhes desnecessários de uma implementação.
- Permite lidar com problemas complexos de maneira mais simples.
- É um conceito fundamental na programação.

### Programação

- Um programa é uma sequência de instruções executadas pelo computador.
- Uma solução precisa ser transformada em instruções que o computador consiga executar.

### Scratch

- Ambiente visual utilizado para ensinar programação.
- Trabalha com blocos.
- Permite utilizar:
  - Variáveis
  - Condições
  - Loops
  - Funções
  - Eventos
  - Sequência de instruções
